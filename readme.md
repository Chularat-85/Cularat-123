# ระบบคอร์สแวร์ช่วยสอน (CAI) เทคโนโลยี ม.1
### วิทยาการคำนวณ และการออกแบบและเทคโนโลยี (อิงหลักสูตร สสวท.)

โปรเจกต์นี้เป็นระบบบทเรียนคอมพิวเตอร์ช่วยสอน (Computer-Assisted Instruction: CAI) แบบเว็บแอปพลิเคชันหน้าเดียว (Single-Page Application) พร้อมระบบจัดการฐานข้อมูล สิทธิ์ผู้ใช้ และคลาวด์สตอเรจผ่าน **Supabase** ออกแบบสำหรับนักเรียนชั้นมัธยมศึกษาปีที่ 1 และครูผู้สอน

## ✨ ฟีเจอร์หลักของระบบ

### 1. ระบบสำหรับนักเรียน (Student Portal)
- **ระบบยืนยันตัวตนแบบตรวจสอบล่วงหน้า:** สมัครด้วยรหัสนักเรียน 11 หลัก โดยระบบจะจับคู่กับฐานข้อมูลโรงเรียนอัตโนมัติผ่าน Database Trigger
- **ระบบแบบทดสอบคู่ขนาน (Parallel Tests):** แบ่งเป็นชุด A และ B (ชุดละ 10 ข้อ) สลับชุด Pre-test และ Post-test ตามเลขท้ายรหัสนักเรียน (คู่/คี่) เพื่อลดการจำข้อสอบ
- **บทเรียนแบบเรียงลำดับ (Sequential Gating):** บทเรียน 5 หน่วย อิงกรอบ สสวท. ผู้เรียนต้องผ่านคำถามตรวจสอบความเข้าใจ (Checkpoint) ในแต่ละหน่วย จึงจะปลดล็อกหน่วยถัดไปได้ และสามารถย้อนทบทวนหน่วยเดิมได้ตลอดเวลา
- **ระบบส่งงานและการจัดการไฟล์:** รองรับการส่งงานทั้งแบบลิงก์ (เช่น Scratch, Canva) และอัปโหลดไฟล์ (รูปภาพ, เอกสาร, วิดีโอ) พร้อมระบบย่อขนาดรูปภาพโปรไฟล์อัตโนมัติในเบราว์เซอร์
- **รายงานพัฒนาการ (Normalized Gain):** คำนวณอัตราการพัฒนาการเรียนรู้ตามสูตรของ Hake พร้อมจัดการกรณียกเว้น (Pre-test เต็ม)

### 2. ระบบสำหรับครูผู้สอน (Teacher Portal)
- **แผงควบคุมผลสัมฤทธิ์:** ดูตารางคะแนน Pre-test, Post-test, ค่า Normalized Gain และจำนวนหน่วยที่นักเรียนเรียนจบ
- **ส่งออกไฟล์ CSV:** ส่งออกรายงานผลการเรียนพร้อม UTF-8 BOM สำหรับเปิดใน Microsoft Excel ภาษาไทยไม่เพี้ยน
- **ระบบตรวจงานและให้ข้อเสนอแนะ:** เปิดไฟล์งานผ่าน Private Signed URL, ให้คะแนน และพิมพ์ข้อเสนอแนะแบบเรียลไทม์
- **คลังสื่อการสอน:** อัปโหลดเอกสารประกอบการสอน (PDF, DOCX, PPTX) หรือแชร์ลิงก์ภายนอกให้นักเรียนดาวน์โหลด

## 🔒 สถาปัตยกรรมความปลอดภัย (Security & Compliance)

1. **Row Level Security (RLS):** เปิดใช้งานทุกตาราง จำกัดให้นักเรียนเข้าถึงได้เฉพาะข้อมูลของตนเอง (`auth.uid()`)
2. **Server-Side Grading (RPC):** การคำนวณและบันทึกคะแนนสอบกระทำผ่านฟังก์ชัน `submit_exam_secure` แบบ `SECURITY DEFINER` ป้องกันการดักแก้คะแนนจากเบราว์เซอร์
3. **Trigger Guards:** 
   - ป้องกันนักเรียนแก้ไขคะแนนหรือข้อเสนอแนะของครูในตาราง `submissions`
   - ป้องกันนักเรียนแก้ไขข้อมูลส่วนบุคคลอื่นในตาราง `students` นอกจากรูปโปรไฟล์
4. **Private Storage Buckets:** Bucket ทั้ง 3 (`photos`, `submissions`, `materials`) ถูกตั้งค่าเป็น Private ทั้งหมด เข้าถึงไฟล์ผ่าน Signed URL ที่กำหนดเวลาหมดอายุเท่านั้น
5. **No Service-Role Key:** ไฟล์ฝั่ง Client ใช้เพียง Supabase Anonymous Key เท่านั้น

## 🚀 วิธีเริ่มต้นใช้งานอย่างรวดเร็ว (Quick Start)

1. **สร้างโปรเจกต์ Supabase:**
   - เข้าที่ [supabase.com](https://supabase.com) และสร้างโปรเจกต์ใหม่
2. **ติดตั้งฐานข้อมูล:**
   - คัดลอกโค้ดจาก `setup.sql` ไปรันในเมนู **SQL Editor** บน Supabase Dashboard
3. **ปิด Email Confirmation:**
   - ไปที่ **Authentication** > **Providers** > **Email** แล้วปิด **Confirm email** เพื่อให้นักเรียนใช้อีเมลสมมติเข้าเรียนได้ทันที
4. **กำหนดสิทธิ์ครู:**
   - สมัครบัญชีครูผ่านหน้า Auth ของ Supabase แล้วนำ User UID ไปรันคำสั่ง `INSERT INTO public.teachers (user_id) VALUES ('<UID_ครู>');`
5. **เชื่อมต่อ Web Application:**
   - เปิดไฟล์ `courseware.html` แก้ไขตัวแปร `SUPABASE_URL` และ `SUPABASE_ANON_KEY` ที่ส่วนต้นของ `<script>` ให้ตรงกับค่าใน **Project Settings** > **API**
6. **เริ่มใช้งาน:**
   - เปิดไฟล์ `courseware.html` บนเบราว์เซอร์ หรืออัปโหลดขึ้นบริการ Web Hosting (เช่น GitHub Pages, Vercel, Netlify) ได้ทันที

## 🛠️ ข้อกำหนดทางเทคนิค (Tech Stack)

- **Front-end:** Vanilla HTML5, CSS3, JavaScript (ES6+), ฟอนต์ Google Sarabun
- **Database & Auth & Storage:** Supabase (PostgreSQL 15+, PostgREST, GoTrue Auth, Storage API)
- **Dependencies:** `@supabase/supabase-js@2` (ผ่าน CDN)
- **Client Requirements:** เบราว์เซอร์มาตรฐานสมัยใหม่ (Chrome, Edge, Firefox, Safari) รองรับหน้าจอตั้งแต่ 360px ขึ้นไป
